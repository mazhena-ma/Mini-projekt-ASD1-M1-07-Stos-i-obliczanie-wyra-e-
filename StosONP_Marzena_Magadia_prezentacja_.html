05
Gdy pojawia się nawias otwierający, zapisuję go na stosie. Przy zamykającym sprawdzam, czy tworzą parę.
Poprawny przykład
{ [ ( 2 + 3 ) ] }
Wszystkie nawiasy pasują.
Błędny przykład
([)]
Nawiasy zamykają się w złej kolejności.
Czym jest ONP?
Odwrotna notacja polska — operator zapisujemy po liczbach.

2 + 3 * 4 → 2 3 4 * + → 14
Najpierw wykonywane jest mnożenie, dopiero potem dodawanie. Dzięki ONP można obliczać wynik bez ponownego analizowania priorytetów operatorów.
